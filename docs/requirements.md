# KDP Helper：个人绘本制作工具需求草案

版本：v0.1 需求基线 · 日期：2026-09-16 · 状态：作者已批准按此方向实施。

批准记录：作者强调“先按官网明确规格、色彩，避免生成工作白做”，并授权处理实现细节。每本书的出版参数仍需在工具中由作者明确确认。首版实际能力和未验证边界见 `verification.md`。

本文记录“要解决什么问题、工具怎么用、做到什么算完成”，不是技术实施计划。已确认需求与建议方案分开标注；待确认事项不视为作者已同意。

## 1. 一句话定义

一个给作者自己使用的绘本制作工具：**先明确出版与图片规格，再输入内容，通过已有 AI 服务生成候选图片，挑选并排版，最后导出用于 KDP 上传的内页 PDF 和封面 PDF。**

作者负责创意、选择和最终确认；工具负责提示规格、调用模型、保存素材、重复操作、排版与文件检查。不是单纯的生图界面，也不是面向其他用户经营的平台。

## 3. 首版建议范围

本节是为了让需求可以执行而提出的建议，须作者确认。

- 使用方式：电脑本机启动、浏览器操作，单人使用；项目与素材保存在本机。
- 出版类型：先支持 KDP 彩色平装绘本，暂不覆盖精装、Kindle 电子书或其他出版平台。
- 初期验证规格：先打通 8.5 × 8.5 英寸方形绘本、高级彩色、白纸；同时支持内页出血与不出血。
- 不开放任意自定义开本；其他尺寸在完成对应规则核验后加入预设，避免提供看似可选但未验证的规格。
- 编辑方式：少量固定图文模板，加文字修改、图片替换和裁切调整；不做通用设计软件。
- 生图方式：首版接通一种 coderplan-ai 生图配置，允许选择已验证可用的模型和参数；不同时建设多家供应商市场。
- 文本辅助：支持用文字模型协助整理页面内容和画面描述；作者可全部手动填写，不强制每一步都调用模型。
- 发布边界：首版完成出版文件与上传说明，由作者在 KDP 上传、预览、确认发布；自动上传不作为首版依赖。

首版不做的内容：商业化账户体系、团队协作、素材交易、复杂绘画修图、自动广告运营、销量分析，以及自动登录并代替作者点击发布。

## 4. 完整使用流程

```text
新建一本书
  → 选择出版规格，查看图片要求
  → 输入主题或逐页文字
  → 确认内容清单、画风和页面模板
  → 生成少量样张
  → 确认方向，生成其余页面的候选图
  → 逐页挑选、修改、重画
  → 预览整本，完成封面
  → 检查出版文件
  → 导出内页 PDF、封面 PDF、上传说明
  → 作者在 KDP 上传、预览并确认发布
```

允许随时返回修改，但工具必须明确哪些结果因此需要重新确认；不能修改规格后继续把旧文件标成最新版。

## 5. 功能需求

### F01：创建和继续制作一本书

- 新建项目时填写工作名称；正式书名、作者署名可以稍后补充。
- 每本书独立保存规格、文案、提示词、候选图、选图结果、排版和导出记录。
- 可关闭工具后重新打开项目，继续未完成的工作。
- 自动保存已完成的操作，并显示保存状态；保存失败时明确提示，不能显示已保存。
- 导出文件不能替代项目源数据，不能出现“导出后就没法改”的情况。

### F02：先给作者一张明确的规格单

作者选择出版预设和出血方式后，工具展示：

| 要告诉作者的事项           | 显示方式                                                       |
| -------------------------- | -------------------------------------------------------------- |
| 最后拿到手的书有多大       | 成品宽高，英寸与毫米并列。                                     |
| 上传 PDF 每页有多大        | 区分成品尺寸与包含出血的文件尺寸。                             |
| 图片应生成成什么形状       | 针对所选版式给出目标宽高比。                                   |
| 图片至少需要多少像素       | 按最终放置面积及裁切结果计算，不仅显示 DPI 标签。              |
| 哪些地方不能放字或动物主体 | 展示裁切线、出血区、文字安全区、装订侧。                       |
| 这本书需要多少页           | 展示所选印刷组合允许的页数、计划内页数、当前实际页数。         |
| 目前模型能否满足要求       | 分别显示模型支持的请求尺寸和预期印刷要求；未知能力标“待验证”。 |

默认向作者解释“为什么要这样选”，不要求其先学习印刷术语。辅助线仅用于编辑与预览，不印入出版 PDF。

规格与图片要求联动：整页背景和半页插画的像素需求不同；切换模板后重新计算，不能对所有插画一律套用整页尺寸。

### F03：把文字想法整理成逐页内容

支持两种输入：

- 简述一本书，例如“为幼儿做一本 A–Z 动物认知绘本，画风温暖简洁”。工具辅助生成页面清单，作者确认后才进入批量生图。
- 作者已有内容，直接输入或粘贴逐页文案与画面要求，不强制使用 AI 改写。

每页至少包含：页面类型、主题/主体、显示文字、画面描述、所用模板。

可增删、排序和修改页面；工具显示操作后的总页数。扉页、版权页、结束页和空白页都计入内页总数，封面不混入内页。

AI 生成的内容是草稿，不自动确认事实、拼写、年龄适宜性或版权。以 A–Z 为例，需要检查字母是否完整、动物名称是否正确对应字母、有没有不符合读者认知的生僻内容；不自动生成虚假的版权或授权声明。

### F04：确定画风与生成要求

- 可通过文字描述画风，也可导入自己有权使用的参考图。
- 整本书保存共用要求，例如色彩、线条、背景复杂度、角色特征、适龄程度和文字留白。
- 工具把共用要求与每页画面描述组合为可查看、可修改的提示词，作者不必每页重复填写。
- 图片中的阅读文字默认不交给生图模型绘制：字母、名称、句子由排版工具独立放置。
- 先选少量页面做样张，作者确认方向后再批量生成。建议默认 2–3 页，数量可调整。
- 参考图支持情况以接口实测为准；若模型不支持，要明确提示，不得静默忽略。
- 画风或角色一致性是努力目标，不承诺模型每次都完全一致；保留作者审核环节。

### F05：调用现有 AI 服务

- 提供一次性配置入口：服务地址、API Key、生图模型；文字辅助需要的模型配置单独列出。
- 优先对接 coderplan-ai；现有本地文档显示有图片生成与参考图编辑调用方式，但正式接入仍需小样验证。[L1]
- Key 仅用于本机后端发起模型请求，不放入网页公开代码、项目导出包、日志、错误截图或 PDF。
- 配置存在不等于接口可用；连接检查与实际生图验证分开，可能收费的验证在执行前说明。
- 支持本地图片导入作为候选，允许作者使用在其他工具中生成的素材；不自动操作第三方会员账号。
- 不假设某个聊天订阅或当前对话中的生图能力可以免费、稳定地供独立工具调用。无可用接口时可走导入路径，但不能宣称自动生图已经接通。

### F06：生成任务和费用控制

- 支持生成单页、指定多页或尚未完成的页面。
- 每页候选数量可调整，建议默认 1 张，需要时再补图，避免默认一次生成大量候选。
- 执行前明确显示页数、候选数量、模型和请求参数；只有存在可信价格配置时才显示费用估计，否则标明“费用未知”。
- 批量任务显示每页等待、执行、成功、失败或结果待确认状态；完成一张就保存一张。
- 支持暂停后续任务，不承诺取消已经发送的请求或退回其费用。
- 一个页面失败不能使整本进度丢失；成功页面不自动重跑。
- 对可能已经被服务端接受的超时请求，不盲目自动重试；优先查询任务结果，无法查询时标“结果未知”，由作者确认是否再次付费调用。
- 恢复任务时先检查已有结果；重启应用不能静默重发进行中的请求。
- 下载生成结果并保存本地文件，不仅保存可能失效的临时链接。保存失败应进入“待取回/保存失败”，而不是简单标记为生图失败并立即重画。

### F07：挑选、比较和重画

- 按页面组织候选图，能放大查看、比较，并选择一张用于该页。
- 单页可修改描述后继续生成，或导入替代图片；旧候选和旧选中结果保留。
- 新候选生成后不自动覆盖作者已经选好的图片。
- 每张候选保存关联页面、生成时的提示词、模型、请求与实际尺寸、创建时间；支持回查其来源。
- 候选图选中前后都检查真实像素，不能只信接口请求参数或图片 DPI 元数据。
- 允许提示动物画错、文字乱码、风格不符等问题；首版不承诺自动视觉模型能判定所有质量问题。

### F08：轻量排版和整书预览

首版建议提供两类模板：图片配独立文字区、图片铺底配安全区域内的文字。每一类都需要分别验证出血与不出血行为。

作者可以修改文字、在预设范围内调整字号与颜色、切换模板、缩放/移动图片裁切位置、替换图片、调整页序；不提供无限画布或任意图层系统。

需要具备：

- 页面缩略图、单页查看及左右页阅读预览；跨页仅用于阅读预览，不把两页拼成一页提交。
- 对文字溢出、缺字、低分辨率和缺图给出具体页码及原因。
- 缩放裁切后重新计算有效分辨率，裁切不应偷偷拉伸图片。
- 图像主体是否过于靠边由作者结合辅助线确认，不能仅靠文字框检查宣称整页内容安全。
- 预览和最终 PDF 使用相同内容、字体与布局数据；最终确认必须能够查看实际生成的 PDF，不能只看网页近似效果。
- 可以导出供检查的草稿，即使尚有问题；草稿与正式出版文件明显区分，不提示可直接上传。

### F09：封面也是首版闭环的一部分

- 复用同一画风和生图选择流程，生成或导入封面图片；允许复用已选插画。
- 提供简单封面模板，作者编辑书名、作者署名及可选的封底简介。
- 程序负责组合封底、书脊和正面，并按最终页数与印刷选项计算尺寸；不能只导出正面图片冒充完整封面。
- 书脊尺寸由内页最终页数决定；改变页数或纸张后封面必须重新计算。
- 首版短绘本不排书脊文字；保留书脊背景，并说明这与完整封面仍有书脊区域并不矛盾。
- 默认采用由 KDP 添加条码的路径，按官方模板预留封底区域；不生成虚假 ISBN 或条码。
- 允许先保存内页 PDF，封面未完成时只能标记“内页已导出”，不能标记“整本出版文件已齐”。

### F10：检查、导出与上传交接

导出前给出检查列表，结果分为“阻止正式导出”“需作者确认”“通过”。

正式导出的阻止项至少包括：规格或页数不合法、缺图、文字溢出或字体缺字、有效像素不足、文字侵入已定义的禁放区域、封面仍对应旧页数、PDF 页面尺寸不符、字体未正确嵌入、出现裁切辅助线或模板占位内容。导出器不能可靠检查的事项，不得自动标成通过。

作者确认项包括：内容正确性、适龄程度、画风与角色、主体裁切、图片/字体使用权和印刷色差预期。

输出：

| 文件               | 用途                                                                         |
| ------------------ | ---------------------------------------------------------------------------- |
| `interior.pdf`     | 按顺序排列的完整内页，不含封面。                                             |
| `cover.pdf`        | 封底、书脊和封面正面组成的单页展开文件。                                     |
| `upload-notes.txt` | 本次使用的尺寸、印刷选项、出血方式、页数、导出时间，以及上传后要核对的事项。 |

文件进入新的版本目录，不能无提示覆盖旧导出；三份文件对应同一个内容快照。导出失败保留原项目和旧文件，不留下被误当作成功结果的半成品。

上传说明提示作者按相同参数设置 KDP，完成 Print Previewer 检查、AI 内容申报及最终发布确认。**本地检查通过只代表工具检查通过，不等于 KDP 已审核通过。**

## 6. 出版规格与生成规格的关系

以下规则来自 KDP 官方文档，核对日期为 2026-09-16；实现时须再次核对。工具的选择范围可以小于 KDP 支持范围，但不能把未验证组合当作已支持。[S1][S2][S3]

### 6.1 内页

- 不出血：PDF 页面宽高等于成品宽高。
- 出血：PDF 宽度为成品宽度加 0.125 英寸，高度为成品高度加 0.25 英寸；上下和外侧留出血，左右页的外侧方向不同。
- 全书只要采用需要出血的页面，整份内页 PDF 使用统一出血尺寸；不能混合页面文件大小。
- 安全边距按官方页数档位计算，模板可以预留更多空间。计算与提示必须区分从文件边缘量还是从裁切线量。
- 内页导出为单页序列，字体嵌入，不包含可见裁切标记；透明对象和图层按提交要求处理。
- 为使工具中的页数与平台处理后的页数一致，正式导出采用偶数内页数；若当前为奇数，先提示作者确认补白页及其位置，再确定最终页数和封面尺寸，不能静默补页。
- 初期示例规格 8.5 × 8.5 英寸：高级彩色白纸为 24–590 页，标准彩色白纸为 72–600 页。因此 32 页示例不能选标准彩色。[S1]

### 6.2 图片

目标是图片在最终放置尺寸下至少达到 300 DPI，而不是把一个数值标签改为 300。[S1]

工具的计算原则：

```text
所需像素 = 向上取整（最终放置尺寸，单位英寸 × 目标 DPI）
有效 DPI = 当前用于该放置区域的像素数 ÷ 放置尺寸，单位英寸
```

宽、高都要满足；发生裁切时以裁切后的可用像素和最终占用区域检查。

例如整页铺满 8.5 × 8.5 英寸有出血的页面：PDF 为 8.625 × 8.75 英寸，按 300 DPI 计算至少约 2588 × 2625 像素。这是根据官方页面公式算出的图片需求，**不代表生图接口一定接受这个请求尺寸**。

如果模型返回像素不足，工具给出明确选择：换已验证的高分辨率配置、缩小图片占用面积/换模板、导入合格图片，或仅保留为草稿。首版不把普通插值放大当作恢复真实细节的保证，也不把 AI 超分辨率作为默认必做能力。

### 6.3 封面

封面独立计算，不能把内页出血公式直接用于封面。[S3]

```text
封面总宽 = 封底宽 + 书脊宽 + 正面宽 + 两侧出血
封面总高 = 成品高 + 上下出血
```

书脊与纸张、印刷选项和最终页数联动。即使内页不出血，封面仍按要求留出血。校验尺寸时与官方 Cover Calculator 模板对照；封面文字与书籍资料保持一致，保留条码区。[S3][S5]

### 6.4 不是软件能够替作者保证的事项

- AI 生成内容按 KDP 要求由作者申报，包括生成的插画；工具保留素材来源记录用于辅助填写，不擅自提交申报。[S4]
- 作者确认图片、文字和字体的使用权，不因“由 AI 生成”自动认定可以任意使用。
- 色彩在屏幕与印刷之间可能存在差异；导出记录实际色彩处理，不能把未实现的 CMYK 转换或印前检查显示成通过。[S3]
- 页面、字体、色彩和透明处理方案需要用样张 PDF 验证；首版验收包含 KDP 在线预览人工检查，实物样书建议作为正式发行前的进一步检查。

## 7. 修改与结果失效规则

| 作者的操作                   | 工具必须如何处理                                                       |
| ---------------------------- | ---------------------------------------------------------------------- |
| 修改页面显示文字             | 更新排版并重查溢出；通常不重画插图；已有出版导出标记不是当前版本。     |
| 修改页面画面要求             | 保留旧图，但将该页选图标为待确认；不能假装旧图已体现新要求。           |
| 改变整本画风或参考图         | 提示受影响页面需要重新确认，不自动删除图片或批量重画。                 |
| 替换图片或调整裁切           | 重新检查分辨率、布局与选图状态。                                       |
| 增删或移动页面               | 更新页数、左右页关系及出血方向；改变总页数时封面重新计算；旧导出失效。 |
| 修改成品尺寸、出血或印刷选项 | 重新生成规格单、重新检查内页与封面；不自动重新消费额度。               |
| 修改 Key 或模型配置          | 只影响后续生成，已保存素材仍可使用并保留原模型记录。                   |

“失效”指不再对应当前项目，旧版本文件仍保留，不代表它被损坏或删除。

## 8. 异常与安全要求

- Key 错误、额度不足、模型不存在、参数不支持、限流、超时分别给出可理解的提示，不向作者暴露完整凭据或原始敏感响应。
- 批量过程可暂停，选图与文字编辑不因某张图耗时较长而丢失。
- 磁盘不足或图片保存失败时停止启动新的生成任务，说明哪些结果尚未保存，避免继续消耗额度。
- 图片文件损坏或临时链接失效时指出具体候选；不覆盖其他可用版本。
- 删除项目或已选图片需明确确认；首版不做自动清理原稿。
- 本机无账户模式仅适用于本机访问，默认不暴露到公网或局域网。若以后需要远程访问，另行评估访问保护，不沿用无保护配置。
- 自动保存不是备份；项目文件应可由作者复制备份，不能包含明文 Key。首版不建设云同步。

## 9. 界面信息结构建议

建议一个工作台，四个主要阶段，而不是一组互不相连的小工具：

1. **规格与内容**：书本参数、规格单、主题和页面清单。
2. **生成与选图**：画风设置、任务进度、逐页候选、重画和选中。
3. **排版与封面**：内页缩略图、单页编辑、阅读预览、封面编辑。
4. **检查与导出**：定位问题页、查看实际 PDF、导出文件及上传说明。

设置入口仅承载服务地址、Key、模型及存储位置等必要配置。颜色、视觉风格、组件库和页面布局尚未设计，本节不锁定技术框架。

## 10. 示例：制作一本 32 页 A–Z 动物绘本

以下只是用于讨论和验收的示例，不代表作者已确认书名、年龄、语言或页数。

1. 作者选择方形高级彩色平装及出血方式，看到尺寸与图片要求。
2. 输入 A–Z 动物认知主题，确认 26 个动物、单词、短句和画面要求。
3. 一份示例内页安排：第 1 页扉页、第 2 页版权信息、第 3 页导读、第 4–29 页 A–Z、第 30 页复习、第 31 页结束、第 32 页作者确认的留白页，共 32 页；封面另计。
4. 先生成 A、B 两页样张，作者确认画风和文字位置。
5. 继续生成其他页面；对不满意的页面补图，其他页面保持不变。
6. 所有插画选定后检查整书，处理扉页和复习等页面；不假设只有 26 张动物图就自动构成全部书稿。
7. 生成并挑选封面素材，确认书名、署名及封底，按最终 32 页排封面。
8. 查看最终 PDF 和检查结果，导出出版文件，再由作者完成 KDP 上传预览。

## 11. 首版验收标准

以下验收依赖第 13 节范围决策完成。样书可以更换，但要覆盖同样的能力。

| 编号 | 验收场景     | 通过标准                                                                                                                                        |
| ---- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| A01  | 先定规格     | 生图前可看到成品尺寸、PDF 尺寸、版式对应的像素要求和安全区；不需要手算。                                                                        |
| A02  | 接通 AI      | 使用作者批准的 coderplan-ai 配置完成真实小样请求，正确保存返回图片与实际尺寸。                                                                  |
| A03  | 内容准备     | 能把一个主题整理成可修改、可排序的页面清单；不经确认不批量出图。                                                                                |
| A04  | 候选选择     | 同页至少两张候选可比较，选中其中一张；补图不会覆盖选中结果。                                                                                    |
| A05  | 任务恢复     | 一页失败不丢失其他页面；重启后保留已完成图和选图，未知结果不会自动重发。                                                                        |
| A06  | 小幅修改     | 改文字不必重画，改图片可单页完成；受影响检查和旧导出状态正确更新。                                                                              |
| A07  | 真实清晰度   | 请求尺寸与实际尺寸不同、以及放大裁切导致 DPI 不足的情况能被识别；阻止相应正式导出。                                                             |
| A08  | 内页文件     | 实际 PDF 的页数、页面尺寸、顺序、字体、图文布局符合选定配置；不含封面及辅助线。                                                                 |
| A09  | 封面文件     | 实际 PDF 包含封底、书脊和正面，尺寸与最终内页/官方模板一致；变更页数后旧封面不能继续通过。                                                      |
| A10  | 错误定位     | 缺图、溢出、缺字或过期封面能定位到页面/区域并说明修改方法。                                                                                     |
| A11  | 文件持久化   | 关闭再打开可继续编辑；生成图片不依赖原临时链接；导出失败不破坏已有成果。                                                                        |
| A12  | 单人使用边界 | 不需要本工具的注册或付费账户；生图可能按外部服务收费，执行前明确说明；Key 不进入导出包或日志。                                                  |
| A13  | 端到端样书   | 完成一本样书的两份 PDF；作者实际上传 KDP 并检查预览，记录并解决尺寸、缺页、字体等工具可控制问题；不以平台最终销售审核通过作为软件唯一验收条件。 |

正式验收不能仅凭网页截图；需要检查最终文件。受限于 Key、额度或账号而未执行的项目必须标记“未验证”，不能记为通过。

出血和不出血两条路径都须有文件检查案例；包括奇数页补白确认、页序变化后的左右页方向，以及增页后封面尺寸更新。

## 12. 实施顺序建议，而非当前开发授权

1. 对齐本需求，确认首版规格、内容和交互边界。
2. 用少量实际图片验证 coderplan-ai 接入、清晰度和画风，再做 2–3 页 PDF 与封面尺寸小样。
3. 在小样确认后实现完整页面清单、任务保存、候选选择、模板排版和正式导出。
4. 用整本示例完成端到端验收，并由作者进行 KDP 上传预览。

优先验证“能不能做出需要的文件”，不先搭庞大的软件框架。不锁定具体模型名称、前后端框架、数据库或 PDF 库；选型需要服从最终导出效果与操作简单程度。

开源调研可作为实现参考，见同目录 `research/2026-09-16-open-source-landscape.md` 与 `research/2026-09-16-print-pdf-options.md`；不将未经验证的项目宣称当作验收证据。
